Eckdaten unter einem Angebotstext: drei Paare (Begriff oben, Wert darunter), eine
Haarlinie darüber, `grid-cols-3` ab `sm`.

## Use
- Der Begriff steht in `.meta-line` (11 px, `ink-45`), der Wert in 14 px `ink`.
  Auf Olive: Begriff `cream-70`, Wert `cream`.
- Immer **drei** Paare — bei vier wird die Zeile auf dem Telefon zu eng; dann zwei
  Blöcke oder eine Kursliste.
- Fakten wiederholen keine Zahlen, die schon im Fließtext stehen.

## Nicht
Kein Icon vor dem Wert, keine Rahmen, keine Kästchen — nur die Linie und der Weißraum.

## Props
`items` (Paare) · `inverse`
