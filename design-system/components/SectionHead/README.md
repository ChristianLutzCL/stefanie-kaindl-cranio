Zentrierter Sektionskopf: Label, Serif-Headline, optional ein Absatz darunter.
Der Standardbaustein, wenn eine Sektion keine eigene Spaltenaufteilung braucht.

## Use
- Reihenfolge: Label (`caps`) → 24 px → `.d2` in der Serif → 24 px → ein Absatz
  (14–15 px, `ink-600`, max 36 rem).
- Auf Olive: Label `inverse`, Headline `cream`, Absatz `cream-80` — nicht `cream-70`
  (3,5:1) für Kleinschrift.
- Der Block ist zentriert und max 42 rem breit; darüber hinaus wächst der Text nicht.

## Props
`label` · `title` · `children` (Absatz) · `inverse`
